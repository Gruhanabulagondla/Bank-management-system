# Bank Account Management System

A simple Python-based Bank Account Management System for managing bank accounts and transactions.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Store account data using JSON
- Input validation

## Technologies Used

- Python
- JSON
- File Handling

## How to Run

Run the Python file:

```bash
python bank_management.py
